# Зелёный рубеж · разлом реальности

Браузерная игра о защите сада: 30 уровней в трёх мирах, 8 растений, 5 видов зомби, косилки и сохранение прогресса. Собственная графика, знакомая механика защиты дорожек и кот, у которого другие планы на законы физики.

## Просто играть

Откройте `ИГРАТЬ.html` двойным щелчком в современном браузере и нажмите «Начать игру». Вся игра и музыка внутри одного файла: Интернет, установка и сервер не нужны. Кнопка «Музыка» включает и выключает весь звук; выбор сохраняется. Музыка начинает играть после нажатия «Начать игру».

## Разлом реальности

Нажмите **R** или «Сломать реальность». Первый заряд доступен сразу. На 12 секунд сад превращается в космос. Три эффекта чередуются, начиная с разного эффекта на каждом уровне:

- **Котосмос.** Кот-капитан в летающей тарелке обращает до четырёх зомби в союзников. Они до 24 секунд сражаются на вашей стороне и стреляют звёздами. Первым вербуется ближайший к дому враг.
- **Гороховая сингулярность.** Растения парят над землёй, снаряды превращаются в быстрые кометы с двойным уроном и отбрасывают врагов.
- **Обратный четверг.** Зомби идут назад и не кусаются, растения восстанавливают здоровье, а из будущего прибывает дополнительное солнце.

Между разломами заряд растёт на 0,8% в секунду, 7% за побеждённого врага и 3% за собранное солнце. Во время эффекта заряд не копится. Пауза останавливает таймер способности. Следующий эффект указан под заголовком разлома.

## Музыка

**Garden After Dark** — оригинальный электронный саундтрек, синтезируемый Web Audio API: бас, ударные, аккорды, арпеджио, ведущая мелодия, эхо и реверберация. Три мира имеют свои темы. Последняя волна делает аранжировку плотнее, разлом включает дроп на 142 BPM. Пауза и переход в другую вкладку останавливают музыку и бой. Для продолжения нажмите «Продолжить».

Нет внешних аудиофайлов, стриминга и загрузок. В браузере без Web Audio игра продолжает работать без музыки.

## Управление

Нажмите карточку растения и клетку поля. Нажимайте на солнца для сбора. **1–8** выбирают растение, **R** — разлом, **P / пробел** — пауза, **Esc** — возврат к горошку. Лопата удаляет растение без возврата стоимости. На сенсорном экране есть кнопки для всех действий.

Уровни открываются последовательно. Каждый мир меняет оформление, поздние уровни добавляют сильных противников; в ночном мире солнце падает реже. Прогресс хранится в браузере, если доступен localStorage.

## Разработка

Никаких npm-зависимостей для игры нет. Исходники: `index.html`, `style.css`, `game.js`, `rift.js`, `music.js`.

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

После изменений обновите автономный файл и архив:

```sh
python3 scripts/build.py
```

## Проверки

```sh
node --check game.js
node --check rift.js
node --check music.js
# Для браузерных тестов нужны установленные Playwright и Chromium.
node tests/smoke.cjs
GAME_URL=http://127.0.0.1:8080/ИГРАТЬ.html node tests/smoke.cjs
```

Браузерные тесты проверяют посадку, сбор солнца, бой, три режима разлома, союзников, паузу, музыку, победу, поражение и открытие уровней. Полное ручное прохождение и баланс всех 30 уровней не проверены.
