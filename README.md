# Зелёный рубеж

Браузерная игра о защите сада: 30 уровней в трёх мирах, 8 растений, 5 видов зомби, косилки, звуковые эффекты и сохранение прогресса. Собственная графика, знакомая механика защиты дорожек.

## Запуск

Откройте `ИГРАТЬ.html` двойным щелчком в современном браузере. Этот файл содержит всю игру; Интернет и установка не нужны. Нажмите «Начать игру».

Для разработки откройте `index.html` или выполните из каталога репозитория:

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

Исходники: `index.html`, `style.css`, `game.js`. После изменения исходников пересоберите автономный HTML, встроив CSS и JavaScript в документ.

## Управление

Нажмите карточку растения и клетку поля. Нажимайте на солнца для сбора. Клавиши 1–8 выбирают растение, P или пробел — пауза, Esc — возврат к горошку. Лопата удаляет растение без возврата стоимости.

Уровни открываются последовательно. Каждый мир меняет оформление, поздние уровни добавляют более сильных противников; в ночном мире солнце падает реже. Прогресс хранится в браузере (если доступен localStorage).

## Проверка

`node --check game.js`. Функционально проверены в Chromium: посадка и списание стоимости, сбор солнца, попадание снаряда, победа, открытие уровня, поражение, карта на 30 уровней. Полное прохождение и баланс всех уровней вручную не проверены.
